# GRID弱形式HessianのRomberg収束実験

[English edition](../docs/grid_wf_hessian_convergence.md)

過去の実験では、2ノードの勾配モデルで3 HzのLove波を計算した。
旧記録の深さ表記は0〜20 kmで、(Vs, Vp, ρ) は上端で (200, 400, 1800)、半無限媒質で (320, 640, 2100) である。
入力値はSI単位の浅部モデル（深さ m、速度 m/s、密度 kg/m³）とも整合するが、当時の単位系は未確認である。
中心差分幅 ε が絶対量か相対量か、相対誤差にどのノルムを用いたかも公開資料からは特定できない。
以下は当時の測定値である。

## 勾配

参照値には中心差分（ε=0.01）を使い、位相速度計算の最大レベルを8とした。
現在の低水準関数 `compute_dispersion_romberg` の引数名は `max_steps` である。

| Romberg Level | 勾配相対誤差 | 改善倍率 |
|:---:|:---:|:---:|
| 0 | 4.68e-02 | — |
| 1 | 3.12e-03 | 15.0x |
| 2 | 2.46e-04 | 12.7x |
| 3 | 5.76e-06 | 42.7x |
| 4 | 2.79e-07 | 20.6x |
| 5 | 2.06e-09 | 135.7x |
| 6 | 1.40e-10 | 14.7x |

## Hessian

レベル7の弱形式勾配から中心差分（ε=0.05）で参照値を求めた。

| Romberg Level | Hessian 相対誤差 | 改善倍率 |
|:---:|:---:|:---:|
| 0 | 5.50e-01 | — |
| 1 | 8.86e-02 | 6.2x |
| 2 | 1.88e-02 | 4.7x |
| 3 | 4.63e-05 | 406.7x |
| 4 | 1.84e-05 | 2.5x |
| 5 | 2.16e-07 | 85.4x |
| 6 | 5.85e-08 | 3.7x |

## 測定条件と解釈

別の粗い差分（ε=0.5）では、レベル3の勾配の誤差が約1e-7、Hessianの誤差が約3e-5と報告された。
上表でのレベル3の勾配誤差は5.76e-6であり、それぞれ参照値が異なる。差分誤差の寄与は切り分けられていない。
Hessianで改善が大きかったのはレベル2→3と4→5で、3→4での改善は2.5倍だった。
当時のHessian計算では `max_levels` が5〜6、`tolerance` が1e-6または1e-8だった。
新しいモデルの設定は、そのモデルでの収束を確認して選ぶ。[練習例](../example_jp/README.md)でレベル上限と推定誤差を比較できる。
